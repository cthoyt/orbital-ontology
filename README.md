# Orbital Ontology

An ontology describing atomic and molecular orbitals.

## Contributing

Edit any of the source files in the `src/` directory, then build the output OWL
(XML), OBO, and OBO Graph JSON outputs in the root of the repository with:

```console
$ just build
```
